# BY-LAW/

Original source documents that `docs/01_Authoritative_References/NSS/` is transcribed from.
Not part of the documentation tree itself — kept here so the authoritative source is
alongside the repo for cross-checking REF transcriptions.

- `NSS/` — `NSS BYE-LAW.pdf` + `NSS_Bye_Law.docx`, the official NSS Constitution & Bye-Law.
  Source for REF-001, REF-002, and the REF-003 series.
- `NSS - Mahila Sangha/` — `NSS Mahila Sangha By-Law.pdf` + `NSS_Mahila_Sangha_Bye_Law.docx`,
  the Mahila Sangha's own Constitution & Bye-Law. Source for the
  `docs/01_Authoritative_References/MAHILA_SANGHA/` transcription (22 `REF-MS-XXX` documents,
  complete).

Do not edit these files — they are the reference originals, not working documents. If a REF
transcription under `docs/01_Authoritative_References/` appears to disagree with a file here,
the file here is authoritative (see `docs/00_Project_Governance/AUTH/AUTH-001_Authoritative_Reference_Standard.md`).
