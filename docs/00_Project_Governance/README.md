# docs/00_Project_Governance/

Governance framework (`AUTH/`, `GOV/`, `GDR/`) and concrete engineering standards (`STD/`).

| Folder | Purpose |
|---|---|
| `AUTH/` | Authoritative Reference Standard — governs the REF repository itself |
| `GOV/` | Governance framework standards (GOV-001…005) |
| `GDR/` | Governance Decision Register standard |
| `STD/` | Frozen, code-facing engineering standards (naming, audit, security, master data) |

See each subfolder's `README.md` for a per-document breakdown.
