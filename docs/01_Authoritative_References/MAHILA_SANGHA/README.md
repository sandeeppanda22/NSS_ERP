# docs/01_Authoritative_References/MAHILA_SANGHA/

Nilachala Saraswata Mahila Sangha's own Constitution & Bye-Laws (a registered entity under the
NSS statutory framework, subordinate to NSS — see `CLAUDE.md` §7).

Transcribed from `BY-LAW/NSS - Mahila Sangha/NSS_Mahila_Sangha_Bye_Law.docx` (confirmed by the
project as already validated against the original source PDF, `NSS Mahila Sangha By-Law.pdf`).

Uses a dedicated `REF-MS-XXX` identifier family (see `AUTH-001`), distinct from the `REF-00X`
family reserved for NSS's own Bye-law sections — since Mahila Sangha is a separate, independently
registered entity with its own Bye-Law, not a section of the NSS document.

All 22 documents preserve the source's actual clause numbering (numerals, letters, roman
numerals) exactly, including confirmed gaps/quirks in the source itself (e.g. no labeled "b)"

not corrected or relettered.
