# docs/01_Authoritative_References/

Source-faithful transcription of NSS's Constitution & Bye-Laws and other authoritative
documents. REF documents preserve original wording — no paraphrasing, no ERP interpretation
(see `docs/00_Project_Governance/AUTH/README.md`).

The original source PDFs/docx these REF documents are transcribed from live in `BY-LAW/` at
the repository root, not under `docs/`. Each REF document's "Source Information" block cites
the specific source file under **Source File(s) in Repository**; if a transcription and its
source file ever disagree, the file in `BY-LAW/` is authoritative.

|---|---|
