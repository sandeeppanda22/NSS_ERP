Cross-module database design documentation (distinct from the per-module table designs under
`docs/03_Solution/modules/<module>/04_*_table_design.md`, and from the actual implemented DDL
in `database/ddl/`).

|----------|---------|
| `DATABASE_DESIGN_STANDARDS.md` | Consolidates frozen conventions from all module table-design documents: PK naming, UUID strategy, FK philosophy, audit columns, soft-delete, master-data architecture, naming conventions, module ownership boundaries. |
